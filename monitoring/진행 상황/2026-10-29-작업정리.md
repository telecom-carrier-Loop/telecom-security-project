# 2026-10-29 작업 정리

담당: 김준오

## 1. 오늘 수행한 작업

### 결제 안내

- 카카오페이 버튼 클릭 시 준비 중 안내창을 표시하도록 변경했다.
- 카카오페이 결제 준비 API 호출과 외부 결제 페이지 이동을 제거했다. 기존 테스트 카드 납부는 유지했다.
- 멤버십 업그레이드 버튼은 `결제 시스템은 준비중입니다.` 안내만 표시한다. 실제 결제·포인트 차감·등급 변경은 수행하지 않는다.

### 멤버십 및 등급 관리

- 고객 멤버십을 **일반유저 / Plus / VIP** 세 등급으로 정리했다.
- 초기 요청에서는 Admin을 네 번째 멤버십으로 구현했으나, 후속 요청에 따라 **Admin은 관리자 역할로 구분하고 고객 멤버십에서 제외**했다.
- 고객 홈·멤버십·상점의 등급 표시와 등급별 혜택 조건을 맞췄다.
- 기존 rank 3 멤버십 데이터는 삭제하지 않고 VIP 정책으로 호환한다. 기존 포인트 잔액과 실제 사용자 권한은 변경하지 않았다.
- 관리자 회원 목록에 `등급 변경` 버튼과 오른쪽 현재 등급을 배치했다.
- 버튼 클릭 시 해당 회원 상세의 등급 편집 영역으로 이동하도록 했다.
- 등급 변경은 관리자 권한·CSRF·입력값을 검증하고, 사유와 변경 전후 등급을 감사 로그에 저장한다.
- 미가입 고객을 관리자가 지정하면 포인트 0으로 가입하며, 기존 회원의 잔액은 유지한다.

### 멤버십 화면 구성

- 사용 가능한 포인트 아래에 등급별 업그레이드 카드를 추가했다.
- 현재·하위 등급의 업그레이드 버튼은 비활성화했다. 정해지지 않은 구매 금액은 임의로 표시하지 않았다.
- 등급별 적립률을 오른쪽 사이드바로 분리하고, 멤버십 페이지 안에서만 스크롤을 따라오도록 구성했다.
- 모바일에서는 사이드바를 일반 문서 흐름으로 전환한다.
- 포인트 패널의 과도한 높이와 카드·표 크기를 조정하고, 조회 중·실패·빈 내역을 구분했다.

### 관리자 보안 화면 및 메뉴

- 차단 IP와 차단 계정을 별도 화면·메뉴·전환 탭으로 분리했다.
- 차단 계정 목록에 검색·페이지 이동·새로고침과 마스킹된 이메일·잠금 시각·사유를 제공했다.
- 새 API가 없는 이전 백엔드에서는 기존 관리자 전용 회원 조회 API로 차단된 고객 계정을 조회하도록 호환 처리를 추가했다. 이 경우 고객 계정만 표시된다는 안내를 제공한다.
- 관리자 상단에 사용자 페이지 이동 버튼을 추가했다.
- 왼쪽 메뉴의 스크롤바를 숨기고 간격을 줄였다. 작은 화면에서도 아래 메뉴에 접근하도록 휠·키보드 스크롤은 유지한다.
- 고객 업무·보안 관리·관제 도구 제목에 메뉴 배경보다 밝은 배경색과 여백을 적용했다.

## 2. 발생한 문제와 대응

| 문제 | 확인 및 대응 |
|---|---|
| 차단 계정 화면에서 404 발생 | 실행 중인 Flask가 새 API를 아직 불러오지 않은 상태임을 확인. 호환 조회를 추가하고 최신 백엔드 재시작 방법을 안내함 |
| Admin이 고객 등급에 표시됨 | 관리자 역할과 멤버십을 분리하고, 고객 API·화면에서는 세 등급만 사용하도록 수정함 |
| 포인트 패널과 등급표의 높이·폭이 부자연스러움 | 본문과 고정 사이드바를 분리하고 화면 폭에 따라 카드 배치를 조정함 |
| 왼쪽 메뉴 구분이 약하고 스크롤바가 눈에 띔 | 제목 배경색·메뉴 간격을 조정하고 스크롤바만 숨김 |

로컬 Flask는 코드 변경 후 자동 재시작되지 않을 수 있다. 새 API·정책을 적용하려면 기존 실행 창에서 중단 후 DB 환경변수를 유지해 다시 실행해야 한다. 이번 작업에서 실제 DB 초기화·시드·마이그레이션은 실행하지 않았다.

- 프런트엔드 타입 검사·빌드 및 변경 형식 검사 통과.

- 레이아웃·메뉴·업그레이드 버튼의 코드 검토를 수행했다.
- 브라우저 접근 정책으로 직접 렌더링 검증은 수행하지 못했다. 사용자가 제공한 화면을 근거로 수정했으며, 전체 모바일·키보드 동작 검증이 완료됐다는 의미는 아니다.
