# API 공통 계약 — A

브라우저 주소는 /api 상대 경로, 금액은 원 단위 정수, 시간은 UTC ISO 8601(화면 KST)입니다. Nginx가 X-Request-ID를 생성하고 Flask가 응답/로그에 동일 ID를 연결합니다. 승인된 한 단계 프록시만 신뢰합니다.

정상: `{"success":true,"data":{},"request_id":"..."}`

오류: `{"success":false,"error":{"code":"...","message":"..."},"request_id":"..."}`

코드: 생성 201, 인증 없음 401, 역할 거부 403, 권한 없는 고객 객체 404, 충돌 409, 검증 실패 422, 요청 제한 429, 의존성 장애 503.

상세 요청·응답 필드/필터/페이지네이션은 해당 기능 첫 구현 PR에서 소비 담당자와 확인하여 추가합니다. 문서 작성과 API 구현 완료를 구분합니다.
