# Kubernetes VM 감시 대상으로 확정

사용자 답변에 따라 앞선 물리 PC 기본값을 아래 VM 주소로 변경했습니다. 이전 작업 문서는 당시 기록으로 보존하며 최종 대상은 이 문서를 따릅니다.

| 표시 | VM 주소 | 감시 |
|---|---|---|
| PC1 | 192.168.7.185 | ICMP 및 SSH TCP 22 |
| PC2 | 192.168.7.100 | ICMP 및 SSH TCP 22 |

- 실제 VM에는 Zabbix agent가 설치되었다고 가정하지 않습니다. Zabbix server의 simple check로 관찰합니다. 새 에이전트 설치나 VM 방화벽 변경은 하지 않았습니다.
- Zabbix telecom-services 호스트에 신규 item 50969~50972 생성.
- 이번 작업 중 임시로 추가한 물리 PC 감시 item 50965~50968만 ID/host/key 대조 후 삭제했습니다. 기존 서비스 감시와 PC2 Windows CPU/RAM/C 드라이브 수집은 유지했습니다.
- ON/OFF는 네트워크 응답 기준입니다. 오래된 값·비활성화·지원 안 됨·미수집은 확인 불가로 표시합니다.
- D 드라이브 및 이더넷 RX/TX는 웹 표시·history 조회에서 제거했습니다. 기존 Zabbix 수집 항목 자체는 삭제하지 않았습니다.
- 자동 테스트 5개 및 frontend production build 통과. 두 VM 모두 Zabbix server에서 ICMP 응답 확인.
- 코드만 수정했으며 웹 배포·커밋·푸시는 수행하지 않았습니다. 운영 웹에는 해당 backend/frontend 버전을 배포해야 반영됩니다.
