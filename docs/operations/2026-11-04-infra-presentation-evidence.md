## 작업 범위와 근거

오늘은 기존 인프라 구축·시험 결과를 발표자료로 정리하고 시연 영상과 검증 캡처를 연결했다. 학원 서버를 이 문서 작성 환경에서 직접 재시험하지 않았으며, 사용자 제공 영상·화면, 기존 운영 기록, GitHub main을 근거로 작성했다. 과거 시험을 오늘 새로 수행한 결과로 기록하지 않는다.

코드 기준은 main `54ce11c3e3caa49c2b50ceb2d391b9c057d312c1`이다. 오늘 병합된 [PR #63](https://github.com/telecom-carrier-Loop/telecom-security-project/pull/63)은 공개 관리자 경로 차단 정책을 변경했다. 발표자료 작성 시점의 과거 정책과 구분해야 한다.

## 관리자 접근 정책의 최신 변경

과거 11월 2~3일 기록은 공개 관리자 API를 Flask까지 전달해 익명 401을 확인한 시점이다. **11월 4일 현재 정책은 공개 고객 주소의 관리자 UI/API를 Nginx 404로 차단**한다. 이전 차단 제거 절차를 다시 적용하지 않는다.

- 고객 공통 입구: `https://192.168.3.30`
- 관리 전용 입구: `https://192.168.7.178:9443/admin`
- 관리 전용 입구에서도 허용 PC 정책과 ADMIN 역할 인증을 함께 확인한다.
- [오늘 정책·현장 보고](2026-11-04-public-admin-guard.md)에 공개 경로 404와 관리 전용 로그인·조회, 비허용 PC 차단 보고가 정리돼 있다.
- 실제 VPN, 직접 NodePort 우회 제한, 새 릴리스 도구의 양 노드 현장 재배포는 해당 문서의 후속 항목을 따른다.

PPT의 11·14·21·36·37쪽에 남은 과거 관리자 401/공개 허용 설명은 발표 전에 최신 정책으로 교정해야 한다. 문경구 대본은 현재 정책으로 고쳤으며, 다른 담당자 페이지는 담당자와 확인한다. 당시 검증 결과 자체를 현재 정책 시험 결과로 바꾸어 적지 않는다.
