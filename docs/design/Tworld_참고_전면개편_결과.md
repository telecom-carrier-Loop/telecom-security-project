# T world 참고 전면 개편 결과

작성일: 2026-10-28. 기존 보고서는 보존하며 이번 전면 개편을 별도로 기록한다.

## 참고와 구현 방향

참고: https://www.tworld.co.kr/web/home

T world의 실제 브라우저 DOM과 1440px 화면을 확인해 흰색 2단 헤더, 목적별 탐색, 큰 상품 이미지 캠페인, 겹쳐 놓은 계정 패널, 요금제·혜택·바로가기, 공지와 푸터의 구조를 참고했다. L∞P 로고는 유지하고 독립적인 퍼플 `#4824c7`과 다크 테마 `#c1a7ff`로 교체했다. SKT 상표·로고·판매 조건·상품을 가져오지 않았다.

## 변경 결과

- 고객 공통: 유틸리티와 주 메뉴를 나눈 2단 헤더, 모바일 메뉴, 푸터, 폼·표·카드·상태·페이지 제목을 갱신했다.
- 홈: 수동 3탭 캠페인과 키보드 전환, 실제 계정 요약, 바로가기, 추천 요금제, 혜택·상품 연결, 활동·공지 흐름으로 교체했다. 계정·요금제·상품·공지는 기존 API를 사용한다.
- 인증: 로그인·가입이 새 AuthFrame을 공유한다. 기존 제출 동작은 유지한다.
- 운영: 중립 퍼플 사이드바와 페이지 헤더, 데이터 면의 공통 스타일을 갱신했다. Zabbix·Grafana 업무 계약은 유지한다.
- 스타일: 업무 공통은 `frontend/src/styles/global.css`, 포털·인증·운영 쉘은 후속 `frontend/src/styles/portal.css`로 구분한다.
- 자산: `frontend/public/images/brand/loop-devices.webp`는 로고 없는 새 생성 기기 정물이다(1672×941, 56,252 bytes). 정확한 프롬프트는 인접한 `.webp.json`에 기록했다. 이전 본사 이미지 자산은 보존했으며 새 화면에서는 사용하지 않는다.
- 기준 문서: `DESIGN.md`, `.impeccable/design.json`을 실제 현재 토큰으로 갱신했다.

## 변경 경계

기존 API 소스, 인증 로직, 라우터, 백엔드, 인프라, 패키지와 잠금 파일은 기준 해시와 동일하다. 디자인 파일만 변경했으며 배포·커밋은 수행하지 않았다. 계정과 상품 정보는 기존 데이터 범위 안에서 표시하며 임의 판매 정보로 대체하지 않는다.

## 확인 결과와 한계

Node 24.19 환경(프로젝트 요구 >=22 <23과 불일치, Node 22에서 추가 확인 필요)에서 최종 `npm run typecheck`, `npm run build`, `git diff --check`가 통과했다. 소스 검토에서 발견한 밝은 캠페인 위 다크 테마 포커스 대비는 해당 영역의 윤곽색을 `#4824c7`로 고정해 수정했고 재검토에서 해결로 판정했다. 이는 소스 검토 결과다.

사용자가 이번 차례에 localhost 열기를 허용한 뒤 한 차례 재시도했으나, 저장된 권한 또는 관리 정책으로 브라우저 접근이 다시 거부됐다. 우회하지 않았다. 저장소 밖의 격리 목업 미리보기 서버는 종료했다. 로컬 앱 요청이나 실제 렌더링을 관찰하지 못했으므로 시각 완성도, 모바일 배치, 키보드·접근성의 실제 동작은 검증 완료로 주장하지 않는다. 참고 사이트의 화면 확인과 로컬 구현의 검증 범위는 구분한다.

## 직접 확인

PowerShell에서 아래 명령으로 로컬 화면을 열 수 있다.

```powershell
cd 'C:\Users\user\Desktop\Project\telecom-security-project\frontend'
npm run dev -- --host 127.0.0.1
```

표시되는 로컬 주소에서 홈·로그인·가입·고객 업무·운영 화면을 확인한다. 밝음·어두움 테마, 1440/768/480px 폭, 메뉴 열기·Escape 닫기·포커스 복귀, 캠페인 탭 키보드 전환, 오류·빈 상태와 표의 가로 스크롤은 후속 실제 브라우저 확인 항목이다.
