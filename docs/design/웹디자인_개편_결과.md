# 통신사 웹디자인 개편 결과

작성일: 2026-10-27

## 구현 범위

기존 L∞P 로고와 블루 브랜드를 유지했다. 고객 홈은 이용현황·요금·멤버십과 자주 찾는 업무를 중심으로 정리하고 가상 본사 사진을 제한된 소개 영역에 배치했다. 로그인 화면은 같은 사진과 소개를 보조적으로 사용한다. 관리자는 고정 사이드바·중립 상단 도구 모음·우선 확인할 상태를 먼저 보는 구조로 정리했다.

CustomerLayout, AdminLayout, Dropdown, LoginPage, HomePage, AdminDashboardPage와 공통 스타일을 변경했다. 코드 검토 후 고객 모바일 메뉴의 관리자 경로, Escape 닫기 후 포커스 복귀, 모바일 관리자 관제 도구 접근을 보완했다. 이용량 미수집 문구와 0 분모에 대한 표시 방어도 적용했다. 밝음·어두움 테마, 로딩·오류·빈 상태, 본문 이동 링크, 포커스와 감소된 모션 규칙을 유지한다. API·인증·인가·Zabbix 계약은 변경 범위가 아니다.

## 디자인 근거

참고 조사 대상: [T world](https://www.tworld.co.kr/web/home), [KT](https://www.kt.com), [LG U+](https://www.lguplus.com), [SK텔레콤](https://www.sktelecom.com), [서울대학교](https://www.snu.ac.kr), [KAIST](https://www.kaist.ac.kr/kr). 반복 업무 우선 배치, 제한된 기업 이미지, 목적별 탐색, 상태와 행동의 분리를 적용했다. 동적 T world·KT 화면의 실제 시각 결과는 확인하지 못했으며 특정 요소를 관찰했다고 단정하지 않는다.

디자인 기준은 frontend/src/styles/global.css이며 DESIGN.md와 .impeccable/design.json에 실제 구현을 추출했다. PRODUCT.md는 없으며 새로운 제품 주장이나 사용자 조사 결과를 만들지 않았다.

## 검증과 제한

`npm run typecheck`, `npm run build`와 `git diff --check`가 통과했다. 실행 환경은 Node 24.19이며 package.json 요구 >=22 <23과 버전이 일치하지 않는다. 지원 버전 Node 22에서 추가 확인이 필요하다. 이미지 출처 검사에서는 래스터 1개, 기록 누락 0개를 확인했다.

코드 검토에서 모바일 메뉴 경로·관제 도구·Escape 포커스 복귀 보완을 확인했다. 반응형 CSS와 테마·상태 표현은 소스 기준으로 확인했다. 로컬 127.0.0.1:5173 브라우저 접근은 자동 승인 검토에서 명시적으로 거부되었고 우회하지 않았다. 실제 렌더링·반응형 화면·키보드 실사용·실백엔드 연결 검증은 완료하지 못했으며 후속 확인 대상으로 남는다.

사전 기준 해시 비교에서 백엔드 파일 내용은 변경되지 않았다. 작업 전부터 존재한 backend/app/__init__.py 차이를 이번 디자인 변경으로 간주하지 않는다. 커밋·푸시·배포는 수행하지 않았다.
